# aftersh0.0ck

초등교사 김여진의 포트폴리오입니다.

수업이 끝나도 남는 질문, 작은 시도에서 이어지는 변화.

HTML, CSS, JavaScript로 만든 정적 사이트이며 별도 데이터베이스나 API 키가 필요하지 않습니다.
즐겨찾기는 방문자의 브라우저에 저장합니다.

## 배포

GitHub Pages 주소: https://duwlsey.github.io/profile/

저장소 Settings → Pages에서 Source를 GitHub Actions로 설정합니다.
main 브랜치에 변경 사항을 올리면 Pages 배포가 자동 실행됩니다.

## 도구 목록 수정

`tools.js`의 도구 목록을 수정합니다. 확인한 블로그 원문을 근거로 작성하고,
없는 학년, 기능, 이용 조건, 성과는 임의로 추가하지 않습니다.
필요한 분류를 추가할 때는 `index.html`의 과목·학년 필터와 `app.js`도 함께 확인합니다.

글꼴 라이선스는 `assets/fonts/`에 포함되어 있습니다.
