# aftersh0.0ck

초등교사 김여진의 포트폴리오입니다.

수업이 끝나도 남는 질문, 작은 시도에서 이어지는 변화.

HTML, CSS, JavaScript로 만든 정적 사이트이며 별도 데이터베이스나 API 키가 필요하지 않습니다.
즐겨찾기는 방문자의 브라우저에 저장합니다.

## 배포

GitHub Pages 주소: https://duwlsey.github.io/profile/

저장소 Settings → Pages에서 Source를 GitHub Actions로 설정합니다.
main 브랜치에 변경 사항을 올리면 Pages 배포가 자동 실행됩니다.

## 도구 목록 수정

`tools.js`의 도구 목록을 수정합니다. 확인한 블로그 원문을 근거로 작성하고,
없는 학년, 기능, 이용 조건, 성과는 임의로 추가하지 않습니다.
필요한 분류를 추가할 때는 `index.html`의 과목·학년 필터와 `app.js`도 함께 확인합니다.

글꼴 라이선스는 `assets/fonts/`에 포함되어 있습니다.

분류 기준: 특정 교과가 없는 도구는 자율활동으로 분류합니다. 자율활동 도구는 전학년 표시와 allGrades: true로 학년 필터에 공통 노출합니다. 개인 프로젝트는 프로젝트 분류를 사용합니다. 블로그가 없는 항목의 출처 링크는 GitHub 보기로 표시합니다. 명시되지 않은 학년은 추정하지 않습니다.

정렬·노출: 전체 목록은 tools.js의 등록 순서를 유지합니다. 각 분류 안에서는 학년 없는 공통 항목을 먼저, 이후 초등 1~6학년 순으로 표시합니다. 같은 학년은 등록 순서를 유지합니다. 미지정 학년은 빈 값으로 두고 카드에서 숨깁니다. categories 배열로 교과와 기초학력을 함께 지정할 수 있습니다. 수케치북은 numbercatch 버전이며 수학·기초학력·1학년, 영어 도구는 영어·기초학력에 포함합니다. 핀볼은 6학년입니다. 운영 중인 예약 서비스는 viewOnly 카드로 공개 앱 링크만 제공하며 상세 소개, 소스, 제작 정보는 제공하지 않습니다.
